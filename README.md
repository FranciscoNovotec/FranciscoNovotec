## 🌟 **Destaque: Projetos de TCC**  
Os projetos de **Trabalho de Conclusão de Curso (TCC)** são o ápice de tudo o que aprendemos durante o curso. Confira abaixo alguns dos trabalhos incríveis desenvolvidos pela turma:  

### 💼 **Projetos de Destaque:**  
1. **[Marques Beauty](https://github.com/FranciscoNovotec/tcc-BGMCoders)**: Um site para um estúdio de maquiagem, focado em comunicação e marketing digital.  
2. **[Pet Center Bueno](https://github.com/FranciscoNovotec/tcc-BuenosCorp)**: Plataforma para agendamento e exibição de serviços de cuidados para pets.  
3. **[Doceria Kamis](https://github.com/FranciscoNovotec/tcc-ArrancaDiu)**: Um site institucional para uma doceria gourmet, com integração para vendas externas.  
4. **[DuAllis](https://github.com/FranciscoNovotec/tcc-Encantech)**: Desenvolvimento de um site personalizado para clientes com foco em UX e identidade visual para uma papelaria.
